# Brief -- daily-records-ligacao-flow

**Type**: Feature
**Workflow**: requirements-first
**Date**: 2026-06-21

## Raw Input

On registo diario de atividade 

- The cliente is always mandatory

- the Ligaçao is mandatory but the User can select NENHUMA as an option.

 

When NENHUMA is select in the Ligação input, the User must fill the other fields of an activity.

When the Ligaçao is Folha de Obra or Assistencia Remota The User must select the a Folha de Obra or Assisntencia remota file and the Dates fields are filled automaticly and the User cannot change them.

 

On the List view the Collaborator should be visible in each Item.
