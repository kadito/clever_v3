# Brief — installations-seven-phases

Refactor Instalações e Programações into a 7-phase workflow.

---

## Phases

### 1. SETUP

- Selecionar o cliente
- Tipo de instalação: POS, CPA, balanças, CCTV, Alarmes, (Botões de chamada e relógios)
- Marca, modelo e n.º série (Texto)
- Fornecedor - Text

### 2. Receção do Material

- Equipamento do Cliente (TEXTO - Número Série, Marca e Modelo do equipamento)
- Verificar condição do equipamento — SE FALSE APARECER TODOS:
  - Verificar cabo
  - Fechadura
  - Chaves
  - Testes ao equipamento
- Observações - TEXTO

### 3. Programação / Preparação

- Software
- Identificado na FOLHA com —-----
- (TEXTO - N.º licença) - TEXTO
- Iniciar programação (verificar campos folhas 3 e 4)
- Teste Final a todos os equipamentos e Acessórios

### 4. Preparação Instalação

- Material adicional - TEXTO
- Verificar todos os equipamentos necessários (consulta folha 5 e 6)

### 5. Instalação no Cliente

**Dados Gerais:**
- Nº Fatura
- Nº Guia de Transporte
- Data Instalação
- Técnico Instalação

**Detalhes da Instalação:**
- Data
- Hora Inicial
- Hora Final
- Data Formação
- Hora Inicial
- Hora Final
- Quem recebeu a formação
- Técnico

### 6. Testes

- Anydesk
  - Sim → Código
  - Não → Porquê
- Vectron Connect
  - Sim → Código
  - Não → Porquê

### 7. Finalização

- Dump Lido
- Cópia Segurança
- Foto Instalação
